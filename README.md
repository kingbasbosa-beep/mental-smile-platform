# Mental Smile Platform

Mental Smile Platform is the clean current repository for the Arabic-first Mental Smile ecosystem.

This repository is built from approved sovereign capsules. It does not treat legacy history as current truth, and it does not import old repository contents directly.

## Repository Role

This repository is:

- clean platform home
- current app/runtime home
- current capsule materialization home
- current GitHub/Firebase governance home
- temporary landing publishing source
- future technical presentation source

This repository is not:

- history archive
- old development dump
- legacy landing host
- experimental lab
- backup vault

## Separation Of Responsibilities

The repository separates:

- app runtime
- landing
- website
- presentation
- GitHub governance
- Firebase governance
- Codex/AI rules
- capsule materialization

## Current Rule

No runtime, legacy source, capsule files, Firebase connection, or deployment workflow should be imported until a dedicated approved materialization operation records exactly what is being brought into the clean repository.
