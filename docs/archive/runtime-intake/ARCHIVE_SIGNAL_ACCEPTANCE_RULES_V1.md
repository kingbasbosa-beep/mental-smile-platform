# Archive Signal Acceptance Rules V1

Status: ACTIVE
Date: 2026-07-02

## Acceptance Requirements

An incoming signal/package may be accepted only when all are true:

1. All section, plug, signal, package, magnet, destination, privacy, and retention codes are approved.
2. The traffic sentence passes the Archive Language Guard.
3. The package has the required shape for its family.
4. The destination code exists.
5. The destination accepts the source section, outbox plug, signal family, package family, and magnet.
6. Privacy class is present and allowed.
7. Retention class is present and allowed.
8. No identity leakage or forbidden target exists.
9. The object is admitted to Archive Inbox before any future memory/routing/aggregation.

## Accepted Package

An Accepted Package is a validated package that has passed the full validation order and is eligible for Archive Inbox.

## Accepted Flow

Accepted does not mean aggregated, summarized, analyzed, or routed by a runtime engine. It means the package is constitutionally eligible to sit in Archive Inbox.
