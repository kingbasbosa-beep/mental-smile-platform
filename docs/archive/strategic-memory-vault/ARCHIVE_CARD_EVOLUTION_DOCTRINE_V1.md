# Archive Card Evolution Doctrine V1

Operation ID: OP-ARCHIVE-STRATEGIC-MEMORY-VAULT-FOUNDATION-V1  
Date: 2026-06-24

## Doctrine

Cards are operational memory units.

Strategic Memory preserves card lifecycle history so future reviewers can understand how features, decisions, tools, and rules evolved.

## Tracked Card Events

Strategic Memory tracks:

- Card creation
- Card replacement
- Card retirement
- Card migration
- Card relationship to guides
- Card relationship to section records

## Record Fields

Each card evolution record should include:

- Card ID
- Card path
- Section
- Date
- Purpose
- Related guide
- Related report
- Lifecycle event
- Replacement or successor if any

## Boundary

Strategic Memory does not make cards current.

Current card status remains determined by section-owned card guides or section registries.
