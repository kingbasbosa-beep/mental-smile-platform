# Marketing Asset Types Guide V1

Operation ID: OP-ARCHIVE-MARKETING-ASSET-VAULT-FOUNDATION-V1  
Date: 2026-06-25

## Purpose

This guide defines the initial asset types governed by the Marketing Asset Vault.

## Asset Types

| Asset Type | Purpose | Example Usage |
|---|---|---|
| Logo | Brand or entity identity | Mental Smile logo, provider logo |
| Splash Background | Entry surface background | Splash gateway visuals |
| Room Background | Residential or accessibility room scene | Client Room, Accessibility Room |
| Exit Page Background | Exit/social links surface visual | Residential exit page |
| Button | Clickable visual control | Exit cup, upload button, YouTube button |
| Icon | Small meaning marker | Link icon, audio marker, category icon |
| Card Image | Card identity image | Accessibility cards, Quick Access cards |
| Post Image | Single publication image | Awareness post image |
| Campaign Image | Campaign visual asset | Recovery campaign visual |
| Provider Portfolio Asset | Provider-generated business asset | CV visual, portfolio PDF cover |
| Commercial Template Asset | Commercial profile or generation template visual | CV template background |
| Library Asset | Library content visual | Knowledge card image |
| Accessibility Asset | Accessibility support visual | Accessibility guide image |
| Future Asset | Reserved type for future governed assets | Future template family |

## Classification Rule

Each registered asset must have one primary asset type.

Secondary usage may be documented in the asset card notes.

## Source Rule

The asset type describes the archived source asset.

Runtime deployment copies do not change the source classification.
