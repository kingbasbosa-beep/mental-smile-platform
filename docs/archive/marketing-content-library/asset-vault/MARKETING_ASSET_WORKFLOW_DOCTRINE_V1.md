# Marketing Asset Workflow Doctrine V1

Operation ID: OP-ARCHIVE-MARKETING-ASSET-VAULT-FOUNDATION-V1  
Date: 2026-06-25

## Purpose

This doctrine defines how visual and media assets should move between Technical, Marketing, Archive, and Runtime once asset governance is operational.

## Workflow

Technical Department

↓

Asset Request

↓

Marketing / Media Department

↓

Creates Asset

↓

Archive Asset Vault

↓

Stores Source Asset + Asset Card

↓

Technical Department

↓

Receives Deployment Copy

↓

Runtime

↓

Uses Copy Only

## Source Preservation Rule

The Archive Asset Vault preserves the source asset and card.

Runtime receives a deployment copy.

Runtime never becomes the source of truth.

## Replacement Rule

Replacing a source asset requires:

- Owner approval
- New version record
- Updated asset card
- Updated registry entry
- Operation record

## Foundation Boundary

This operation creates the workflow doctrine only.

It does not move, copy, delete, overwrite, or deploy assets.
