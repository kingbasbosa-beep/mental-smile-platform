# Marketing Initial Asset Inventory Plan V1

Operation ID: OP-ARCHIVE-MARKETING-ASSET-VAULT-FOUNDATION-V1  
Date: 2026-06-25

## Purpose

This plan prepares a future inventory of existing Mental Smile visual and media assets.

No inventory was performed during this foundation operation.

No assets were moved, copied, deleted, overwritten, or registered during this foundation operation.

## Future Inventory Scope

Future inventory may inspect:

- Existing logos
- Splash visuals
- Room backgrounds
- Exit page visuals
- Buttons
- Icons
- Cards
- Post assets
- Provider portfolio visuals
- Commercial template visuals
- Library visuals
- Accessibility visuals

## Future Inventory Fields

- Asset name
- Current path
- Apparent usage
- Runtime copy status
- Source candidate status
- Required asset card
- Related section
- Related operation
- Owner review need

## Inventory Boundary

The future inventory should document what exists before any source-of-truth asset registration.

The future inventory should not delete, move, overwrite, or rename assets.

## Final Rule

Inventory first.

Register with cards second.

Deployment copy updates only after approval.
