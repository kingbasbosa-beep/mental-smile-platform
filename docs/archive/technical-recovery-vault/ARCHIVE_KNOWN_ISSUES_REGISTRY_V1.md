# Archive Known Issues Registry V1

Operation ID: OP-ARCHIVE-TECHNICAL-RECOVERY-VAULT-FOUNDATION-V1  
Date: 2026-06-24

## Purpose

Known Issues Registry defines the standard structure for future technical issue memory.

No runtime issue data is migrated by this foundation operation.

## Registry Structure

| Field | Description |
|---|---|
| Issue ID | Stable issue identifier |
| Title | Short issue title |
| Affected Component | Component, page, service, rule, asset, or document |
| Symptoms | Observed failure symptoms |
| Impact | Technical or operational impact |
| Root Cause | Verified cause when known |
| Fix | Fix applied or approved |
| Preventive Update | Prompt, guide, card, or package update |
| Related Prompt | Prompt ownership record |
| Related Guide | Guide reference |
| Related Card | Card reference |
| Resolution Status | Current resolution status |

## Future Resolution Status Values

- OPEN
- IN_PROGRESS
- RESOLVED
- VERIFIED
- REOPENED
- SUPERSEDED

## Boundary

This registry is a technical memory structure.

It does not execute fixes.
