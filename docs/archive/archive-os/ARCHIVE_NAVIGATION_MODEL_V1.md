# Archive Navigation Model V1

Operation ID: OP-ARCHIVE-OS-FOUNDATION-BLOCKS-A-H-V1

Date: 2026-06-25

## Navigation Mission

Archive navigation must let a future user move by:

- district;
- era;
- artifact type;
- operation;
- relationship;
- search;
- timeline;
- section ownership.

## Primary Navigation

1. Archive Landing
2. Archive Explorer
3. Archive Timeline
4. Archive Search
5. Reports Viewer
6. Card Viewer
7. Guide Viewer
8. Registry Viewer

## Navigation Paths

| User Intent | Navigation Path |
|---|---|
| Understand Archive | Archive Landing -> Doctrine -> Constitution |
| Browse sections | Archive Landing -> Explorer -> District |
| Find event by date | Archive Landing -> Timeline -> Era -> Event |
| Find operation | Archive Search -> Operation ID -> Operation Card |
| Find guide | Archive Explorer -> Guide History -> Guide Viewer |
| Find registry | Archive Explorer -> Registry History -> Registry Viewer |
| Find failure | Archive Explorer -> Failure Knowledge -> Crisis/Recovery cards |

## Navigation Rule

Archive navigation must never depend on Owner or Administrative runtime.
