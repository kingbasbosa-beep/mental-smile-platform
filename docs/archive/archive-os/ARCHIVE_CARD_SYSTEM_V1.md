# Archive Card System V1

Operation ID: OP-ARCHIVE-OS-FOUNDATION-BLOCKS-A-H-V1

Date: 2026-06-25

## Mission

Convert Archive from documents-only memory into a card-addressable knowledge system.

## Card Types

| Card Type | Purpose |
|---|---|
| Historical Event Card | Records a dated historical event |
| Operation Card | Records a significant operation |
| Migration Card | Records movement, separation, or ownership migration |
| Era Card | Records a project era |
| Decision Card | Records a decision and rationale |
| Crisis Card | Records failure, conflict, or risk moment |
| Recovery Card | Records fix, recovery, or restoration pathway |
| Evolution Card | Records architectural or doctrine evolution |

## Minimum Card Fields

- Card ID
- Card Type
- Title
- Date
- Era
- Related Operation
- Related Files
- Related Guides
- Related Registries
- Summary
- Evidence
- Access Class
- Status

## Card Rule

Every major Archive item must become card-addressable over time.
