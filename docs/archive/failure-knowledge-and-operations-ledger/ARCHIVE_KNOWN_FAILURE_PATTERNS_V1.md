# Archive Known Failure Patterns V1

Operation ID: OP-ARCHIVE-FAILURE-KNOWLEDGE-AND-OPERATIONS-LEDGER-V1  
Date: 2026-06-24

## Recurring Patterns

| Pattern | Description |
|---|---|
| Legacy Documentation Drift | Older documents remain visible beside current source documents and confuse future reasoning |
| Route Ownership Drift | Routes become unclear across sections or ownership layers |
| Guide Ownership Drift | Guides exist without a clearly current owner or section boundary |
| Card Ownership Drift | Runtime or documentation items exist without clear card ownership |
| Archive Bypass Risk | Records are marked historical without the referenced content being preserved in Archive |
| Prompt Ownership Drift | Prompts create or modify system items without ownership records |

## Future Additions

Future patterns may be added when repeated failure evidence appears.
