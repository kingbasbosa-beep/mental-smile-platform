# Marketing Machine Archive Requirements V1

## Operation

OP-MARKETING-MACHINE-EXTRACTION-AUDIT-V1

## Status

FORENSIC EXTRACTION ONLY

NO DEPARTMENT CREATION

## What Marketing Must Store

| Stored Item | Archive Location | Retention | Notes |
|---|---|---|---|
| Source Published Profile Reference | Provider Portfolio Vault | Long-term while profile history remains relevant | Preserve profile ID, public URL, live profile version. |
| Source Identity Image / Logo Reference | Provider Portfolio Vault / Marketing Asset Vault | Long-term while asset is used | Preserve storage reference and usage context. |
| Generated CV Asset | Provider Portfolio Vault / Marketing Content Library | Long-term if approved for reuse | Preserve generation date/template/source profile. |
| Official Profile PDF | Provider Portfolio Vault | Long-term if exported/registered | Preserve live profile version used. |
| Business Card Asset | Marketing Asset Vault / Provider Portfolio Vault | Long-term while active or historically relevant | Requires asset card and versioning. |
| Promo Post Asset | Marketing Content Library / Marketing Asset Vault | Long-term campaign history | Requires publication status and versioning. |
| Campaign Package | Marketing Content Library | Campaign lifecycle plus historical record | Requires campaign registry entry. |
| Publication Record | Marketing Content Library | Long-term campaign evidence | Preserve channel, date, status. |
| Performance Report | Archive Strategic Planning Vault | Long-term strategic evidence | Requires aggregation and strategic summary. |
| Success Story | Marketing Content Library | Long-term if consent/legal classification allows | Consent/legal classification required. |

## Where

- Provider Portfolio Vault: profile and portfolio source assets.
- Marketing Content Library: copy, campaign content, posts, success stories, publication records.
- Marketing Asset Vault: visual/generated assets such as cards, post visuals, logos used in campaigns.
- Archive Strategic Planning Vault: performance reports and strategic marketing intelligence.

## For How Long

Default retention is long-term archive retention unless a future retention operation defines expiry, retirement, or replacement rules.

## Archive Requirement Finding

Marketing must store both source references and generated derivatives. Without asset cards, content registries, and publication records, generated marketing output cannot become governed archive evidence.
