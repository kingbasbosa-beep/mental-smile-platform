# Commercial V2 Client Discovery Entry Decision V1

## Current Client Surfaces Reviewed

- Quick Access
- Accessibility
- Library
- Commercial Direct Entry
- External Website

No route connection was changed.

## Option A - Quick Access

Advantages:

- close to Residential client room
- can expose practical links without requiring accounts
- suitable for intent-based user access

Disadvantages:

- Quick Access is personal/support oriented
- commercial discovery may make the room feel less calm
- risks mixing client reflection tools with marketplace browsing

Dependencies:

- approved Quick Access card/links integration
- clear boundary that discovery is external/public browsing, not recommendations

## Option B - Accessibility

Advantages:

- useful for accessible providers/resources
- supports barrier-removal discovery

Disadvantages:

- should not make accessibility room a commercial directory
- risk of confusing accessibility resources with commercial entities

Dependencies:

- accessibility-specific filter policy
- clear separation between accessibility resources and commercial profiles

## Option C - Library

Advantages:

- knowledge context can naturally link to relevant public profiles
- supports learning-first discovery

Disadvantages:

- Library should remain content/resource focused
- profile discovery may distract from knowledge surfaces

Dependencies:

- Library-to-commercial link doctrine
- no recommendation or ranking

## Option D - Commercial Direct Entry

Advantages:

- clean domain boundary
- easiest to explain and govern
- avoids mixing Residential/Accessibility/Library with commercial browsing

Disadvantages:

- needs a dedicated discovery page that does not exist yet
- adds a new user-facing public commercial surface

Dependencies:

- Commercial V2 discovery route
- public listing/search/filter implementation
- visibility rules

## Option E - External Website

Advantages:

- strongest public/web separation
- good for SEO and public discovery
- avoids app room contamination

Disadvantages:

- may require website integration outside current app runtime
- user journey from app to web must be deliberate

Dependencies:

- official website route/page integration
- external web deployment policy

## Recommended Official Discovery Entry Point

Recommended: Commercial Direct Entry backed by public Official Website placement.

Reason:

Commercial V2 discovery is a public commercial browsing layer. It should not be hidden inside Residential rooms, Accessibility rooms, or Library content as its primary entry point. Those sections may reference discovery later, but the official entry should belong to Commercial V2/public web.

## Owner Recommendation

Create Commercial V2 discovery as a dedicated public route later, then expose it through the Official Website and selected section links only after owner review.
