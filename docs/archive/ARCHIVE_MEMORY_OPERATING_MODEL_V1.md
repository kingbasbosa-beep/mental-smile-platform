# Archive Memory Operating Model V1

Operation ID: OP-ARCHIVE-DEPARTMENTAL-VAULTS-AND-SHARED-RESOURCES-FOUNDATION-V1  
Date: 2026-06-24

## Purpose

This operating model defines how Archive memory is separated between departmental vaults and centrally governed shared resources.

## Model

| Layer | Purpose |
|---|---|
| Departmental Vaults | Preserve department-specific records, reports, decisions, assets, and history |
| Shared Tools Vault | Preserve central tool ownership and consumption rules |
| External Accounts Registry | Preserve central account ownership references without credentials |
| Strategic Memory Vault | Preserve why decisions happened |
| Technical Recovery Vault | Preserve how components were built and restored |
| Failure Knowledge Layer | Preserve what failed, why, fixes, prevention, and lessons |
| Global Operations Ledger | Preserve chronological operation records without analysis |
| Provider Portfolio Vault | Preserve provider-generated business assets as sovereign platform assets |
| Marketing Content Library | Preserve marketing and awareness content as sovereign marketing assets |
| Marketing Asset Vault | Preserve source-of-truth visual and media assets while runtime uses deployment copies only |

## Department Rule

Each department owns a vault space inside Archive.

The department does not own Archive itself.

## Shared Resource Rule

Tools and external accounts are centrally governed shared resources.

Departments may consume them according to the Department Tool Access Matrix.

## Credentials Rule

Credentials must never be stored inside Archive.

Archive may record ownership references, account categories, and governance contacts only.

## Failure And Operations Rule

Major failures must create failure records.

Significant operations must create ledger records.

## Provider Portfolio Rule

Provider Portfolio Assets are sovereign business assets.

They are not client data.

Archive remains the source of truth.

Publication platforms are distribution channels only.

## Marketing Content Rule

Marketing content is a sovereign marketing asset.

Archive remains source of truth.

Publication platforms are distribution channels only.

Published content must remain recoverable.

## Marketing Asset Rule

No Asset Without Asset Card.

No Runtime Asset As Source Of Truth.

No Direct Runtime Asset Editing.

Archive Asset Vault Is Source Of Truth.

Runtime Uses Deployment Copies Only.

Marketing View-Only For Existing Archived Assets.

Technical Receives Deployment Copies.

Owner Approves Source Replacement.
