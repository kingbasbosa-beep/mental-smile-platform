# Archive Department Tool Access Matrix V1

Operation ID: OP-ARCHIVE-DEPARTMENTAL-VAULTS-AND-SHARED-RESOURCES-FOUNDATION-V1  
Date: 2026-06-24

## Purpose

Define department tool consumption boundaries.

## Matrix

| Department | Allowed Tools |
|---|---|
| Legal | ChatGPT, document review tools, official authority references |
| Strategic Planning | ChatGPT, Gemini, Analytics, reporting tools |
| Technical | Codex, GitHub, Firebase, Android Studio, Google Cloud |
| Marketing | Canva, ChatGPT, Gemini, social platform consoles |
| Owner | ChatGPT, Codex, GitHub, Firebase, Google Play Console, strategic reporting tools |
| Accounting | Accounting tools, document tools, approved reporting tools |

## Rule

Tool access does not mean tool ownership.

Departments consume centrally governed tools.
