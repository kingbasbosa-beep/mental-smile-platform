Operation ID: OP-ARCHIVE-PROVIDER-PORTFOLIO-VAULT-FOUNDATION-V1

## Purpose

Document how generated provider assets may become future reusable templates.

## Rules

Templates originate from archived provider assets.

Template creation requires ownership review.

Template creation requires archive registration.

Template creation requires version tracking.

## Boundary
