## Asset Types

| Asset Type | Purpose |
|---|---|
| Business Card | Compact provider identity and contact asset |
| Generated CV | Professional provider profile document |
| Portfolio PDF | Profile-based portfolio document |
| Promotional Post | Social/publication-ready provider asset |
| Publication Package | Group of assets prepared for publication |
| Future Templates | Reusable templates derived from reviewed archived assets |
| Future Assets | Future provider business asset families |

## Boundary

Provider asset types are business assets.

They are not client records.
