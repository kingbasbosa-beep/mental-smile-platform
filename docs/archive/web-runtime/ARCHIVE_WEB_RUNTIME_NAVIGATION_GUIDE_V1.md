# Archive Web Runtime Navigation Guide V1

Operation ID: OP-ARCHIVE-WEB-RUNTIME-FOUNDATION-V1

Date: 2026-06-25

Purpose:

Define future navigation logic for Archive Web Runtime without creating UI.

## Navigation Groups

### Core

- Archive Home
- Certification
- Section Registry

### Memory

- Strategic Memory
- Operations Ledger
- Failure Knowledge

### Recovery

- Technical Recovery
- Prompt Library

### Business Assets

- Provider Portfolio
- Marketing Content
- Marketing Assets

### Departmental

- Departmental Vaults

## Navigation Rules

- Archive Home is the future entry surface.
- Certification must remain visible as proof of Archive readiness.
- Operations Ledger must be discoverable from Archive Home and Failure Knowledge.
- Prompt Library must be discoverable from Technical Recovery.
- Marketing Assets must be discoverable from Marketing Content.
- Departmental Vaults must remain separate from Shared Tools and External Accounts but may reference both.

## Forbidden Navigation

Archive Web Runtime navigation must not depend on:

- Owner legacy routes
- Administrative legacy routes
- Commercial runtime
- Monitoring runtime
- Firebase data

## Current Implementation Status

No navigation UI was implemented.

No runtime navigation was changed.
