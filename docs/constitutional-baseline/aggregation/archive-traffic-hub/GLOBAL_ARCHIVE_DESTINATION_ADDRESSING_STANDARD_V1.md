# GLOBAL_ARCHIVE_DESTINATION_ADDRESSING_STANDARD_V1

Status: ACTIVE ADDRESSING STANDARD

## Format

Every Archive destination must have:

- Human title
- Archive destination code

Format:

```text
Destination Name (ARCHIVE_CODE)
```

## Seed Examples

| Destination Title | Archive Code |
|---|---|
| Commercial V2 Registration Packages | `ARC-PKG-CV2-001` |
| Commercial V2 Publishing Packages | `ARC-PUB-CV2-001` |
| Library Demand Signals | `ARC-SIG-LIB-001` |
| Residential Tool Signals | `ARC-SIG-RES-TOOLS-001` |
| Accessibility Audio Signals | `ARC-SIG-ACC-AUD-001` |
| Provider Publishing Queue | `ARC-PUB-PROV-001` |
| Strategic Summary Feed | `ARC-SUM-STR-001` |
| Owner Decision Feed | `ARC-SUM-OWN-001` |

## Rule

Archive destination codes are traceability anchors.

Summary and dispatch packages must preserve the original archive destination code.
