## Dispatch Rule

Archive may produce summary or dispatch packages for destination sections.

Destination sections receive those packages through their inbox plug only.

## Dispatch Requirements

| Requirement | Status |
|---|---|
| Source archive destination code preserved | REQUIRED |
| Destination section code included | REQUIRED |
| Destination inbox plug included | REQUIRED |
| Destination code included | REQUIRED |
| Privacy class included | REQUIRED |
| Retention class included | REQUIRED |
| Direct route destination | PROHIBITED |
| Direct screen destination | PROHIBITED |
| Direct Firestore target | PROHIBITED |

## Section Notes

Owner receives decision feeds through Archive dispatch.

Monitoring receives observability summaries through Archive dispatch.

Administrative receives and sends governed packages through Archive dispatch.
