# LIBRARY_INBOX_AGGREGATION_DOCTRINE_V1

Status: ACTIVE LIBRARY DOCTRINE

## Library Inbox Rule

Library must receive external publishing packages only through:

`LIBRARY_INBOX_AGGREGATION_POINT`

No external section may write directly into Library screens.

No external section may bypass Library Inbox.

## Library Internal Distribution

After a package enters Library Inbox, Library distributes internally using:

- Display Section Codes
- Provider Type Codes
- Category Codes
- Signal Codes

## Library Package Intake

| Intake Item | Required |
|---|---|
| Package Contract | YES |
| Source Outbox Reference | YES |
| Publishing Dispatch Approval | YES when public display is involved |
| Archive Magnet | YES |
| Display Section Codes | YES for display packages |
| Provider Type Codes | YES for provider/center packages |
| Category Codes | YES where category display is required |
| Primary Specialty preserved | YES |

## Library Boundary

Library owns display runtime.

Commercial owns registration/profile preparation runtime.

Publishing owns dispatch approval.

Archive owns historical package retention.
