## Archive Requirements

- Preserve final reviewed package.
- Preserve source list.
- Preserve review status.
- Preserve owner-facing version when approved.
- Preserve retired package reason if package is not used.

No Archive connection is created in this block.

## Owner Requirements

- Owner-facing material must be reviewed.
- Owner direction must be separated from department recommendations.
- Strategic Planning & Intelligence may not create owner authority.

No Owner Cabinet connection is created in this block.

## Retention Rules

- Draft package retained only while in preparation.
- Reviewed package retained according to future Strategic Planning & Intelligence storage rules.
- Approved historical package retained according to future Archive rules.
