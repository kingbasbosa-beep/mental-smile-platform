## Operation

OP-STRATEGIC-MINIMUM-VIABLE-RUNTIME-V1

## Purpose

Generate strategic report outputs from eligible Residential strategic analysis and prepare publication to Owner Strategic Cabinet and Archive Strategic Planning Vault.

## Input

Strategic findings from Strategic Analysis Runtime.

## Report Rules

- Reports must preserve Residential source references.
- Reports must preserve classification.
- Reports must include findings, risks, opportunities, and open questions when present.
- Reports must mark confidence level.
- Reports must identify destination eligibility.
- Reports must not create owner decisions.
- Reports must not execute governance.
- Reports must not create admin authority.

## Eligible Report Types

| Report Type | Source | Destination Eligibility |
|---|---|---|
| Residential Weekly Strategic Input Report | RESIDENTIAL_WEEKLY_SUMMARY | Owner Strategic Cabinet / Archive Strategic Planning Vault |
| Residential Monthly Strategic Review Input | RESIDENTIAL_MONTHLY_SUMMARY | Owner Strategic Cabinet / Archive Strategic Planning Vault |
| Residential Quarterly Strategic Review Input | RESIDENTIAL_QUARTERLY_SUMMARY | Owner Strategic Cabinet / Archive Strategic Planning Vault |
| Residential Risk Intelligence Note | Risk-tagged Residential Summary Package | Owner Strategic Cabinet / Archive Strategic Planning Vault |
| Residential Opportunity Intelligence Note | Opportunity-tagged Residential Summary Package | Owner Strategic Cabinet / Archive Strategic Planning Vault |

## Publication Rules

- Publication requires report eligibility.
- Publication requires destination classification.
- Publication to Owner Strategic Cabinet creates owner review material only.
- Publication to Archive Strategic Planning Vault creates archive strategic intelligence only.
- Publication does not approve platform changes.
- Publication does not create implementation authority.

## Owner Delivery Rules

- Owner delivery destination: Owner Strategic Cabinet.
- Owner delivery output: Owner Review Material.
- Owner delivery must preserve Residential source and Strategic analysis metadata.
- Owner delivery must not create Owner Direction Records unless Owner acts separately.

## Archive Rules

- Archive destination: Archive Strategic Planning Vault.
- Archive output: reviewed strategic intelligence record.
- Archive copy must preserve source package reference, analysis result, classification, report type, and publication date.
- Archive copy must follow Archive Strategic Writer Contract.

## Output Destinations

- Owner Strategic Cabinet.
- Archive Strategic Planning Vault.
