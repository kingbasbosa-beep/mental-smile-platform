# Marketing Storage Registry V1

## Status

FOUNDATION STORAGE REGISTRY ONLY

NO FIREBASE

NO STORAGE CREATED

## Purpose

Define where Marketing and Media records must be stored when future work creates them.

## Storage Registry

| Stored Item | Archive Location | Retention | Current Status |
|---|---|---|---|
| Source Published Profile Reference | Provider Portfolio Vault | Long-term while profile history remains relevant | FUTURE_USE |
| Source Identity Image / Logo Reference | Provider Portfolio Vault / Marketing Asset Vault | Long-term while asset is used | FUTURE_USE |
| Generated CV Asset | Provider Portfolio Vault / Marketing Content Library | Long-term if approved for reuse | PARTIAL_SOURCE_EXISTS |
| Official Profile PDF | Provider Portfolio Vault | Long-term if exported/registered | PARTIAL_SOURCE_EXISTS |
| Business Card Asset | Marketing Asset Vault / Provider Portfolio Vault | Long-term while active or historically relevant | MISSING |
| Promo Post Asset | Marketing Content Library / Marketing Asset Vault | Long-term campaign history | MISSING |
| Campaign Package | Marketing Content Library | Campaign lifecycle plus historical record | MISSING |
| Publication Record | Marketing Content Library | Long-term campaign evidence | MISSING |
| Performance Report | Archive Strategic Planning Vault | Long-term strategic evidence | MISSING |
| Success Story | Marketing Content Library | Long-term if consent/legal classification allows | MISSING |

## Storage Rules

- Marketing stores source references and generated derivatives through Archive destinations.
- Marketing does not replace Archive custody.
- Marketing does not store credentials.
- Marketing does not create Firebase or Storage paths in this foundation.
