# Global Code Gate Doctrine V1

Operation: GLOBAL_CODE_GATE_AND_UNCODED_QUARANTINE_DOCTRINE
Date: 2026-07-02

## Core Rule

No Code = No Authority.

Mental Smile does not treat names, labels, folders, historical markers, old philosophy, or display text as runtime or governance authority.

## Code Gate Requirement

Every active object that participates in current runtime or governance must have an approved code.

This applies to:

- file
- route
- screen
- card
- registry
- rule
- collection
- asset
- localization entry
- signal
- package
- archive destination
- documentation unit

## Authority Boundary

An object may participate in active runtime/governance only when it has both:

1. Approved code evidence.
2. Current registry, ownership, route, runtime, or governance reference.

Textual markers alone provide no authority.
