# Code Gate Capsule Protection Rule V1

Date: 2026-07-02

## Purpose

Protect Capsules, DNA, and AI-assisted future generation from uncoded historical residue and philosophical noise.

## Rule

Capsules and DNA may cite or preserve only objects that have:

- approved code, or
- explicit historical/quarantine classification.

Uncoded objects must not be promoted into Capsule truth.

## AI Context Protection

AI assistants must not infer active authority from:

- names
- folders
- labels
- `[S]`
- strategic/city/commercial/support wording
- old philosophy
- old comments
- historical screenshots or descriptions

AI-assisted output must use current codes and registries as the source of authority.
