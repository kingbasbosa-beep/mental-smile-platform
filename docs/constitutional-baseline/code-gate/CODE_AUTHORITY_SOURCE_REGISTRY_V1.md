# Code Authority Source Registry V1

Date: 2026-07-02

## Approved Code Sources

Approved runtime/governance authority may come only from:

- Section Code
- Route Code
- Screen Code
- UI Card Code
- Signal Code
- Package Code
- Archive Destination Code
- Magnet Code
- Plug Code
- Registry Code
- Rule Code
- Collection Code
- Asset Code
- Localization Key Code
- Operation Code
- Digital Twin Code

## Non-Authority Sources

The following are not approved authority sources:

- `[S]`
- legacy names
- folder names
- old section names
- strategic
- city
- commercial
- support
- temporary
- placeholder
- safe
- unused
- harmless
- old comments
- old display names

## Rule

If an object is important enough to participate in active runtime or governance, it is important enough to have an approved code.
