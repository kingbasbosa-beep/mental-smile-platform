# Textual Marker Neutrality Rule V1

Date: 2026-07-02

## Rule

Textual markers are descriptive only. They are not runtime authority.

## Non-Authoritative Examples

| Marker | Automatically Active? | Automatically Legacy? |
|---|---|---|
| `[S]` | NO | NO |
| Strategic | NO | NO |
| City | NO | NO |
| legacy in a label | NO | NO |
| old folder name | NO | NO |
| old display name | NO | NO |

## Required Interpretation

Every classification must ask:

1. Is there a current route constant?
2. Is there a current router case?
3. Is it imported by active runtime?
4. Is it registered to a current section code?
5. Is it documented in a current screen/route/digital twin registry?
6. Does the current ownership card still claim it?

If the answer is no, the marker alone cannot make it active.
