# S Marker Neutrality Note V1

Date: 2026-07-02

## Note

The marker `[S]` is neutral.

It does not automatically mean:

- active
- legacy
- protected
- public
- obsolete
- strategic
- safe to delete
- required to keep

## Classification Requirement

Every `[S]` file, route, screen, or feature must be classified using code and registry evidence.

## Valid Outcomes

An `[S]` item may be:

- ACTIVE if it has current router/runtime/registry authority.
- LEGACY if current authority is absent and only historical evidence remains.
- PENDING if it is registered but intentionally not current runtime.
- ORPHAN if it exists without current reference.
- PROTECTED if current protected route authority exists.

The marker itself decides nothing.
