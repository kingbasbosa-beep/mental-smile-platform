# Code-Only Active Authority Doctrine V1

Operation: CODE_ONLY_ACTIVE_AUTHORITY_DOCTRINE
Date: 2026-07-02

## Doctrine

Active runtime authority is determined only by official codes, registries, router wiring, current runtime references, and current ownership records.

Textual markers have zero authority by themselves.

## Neutralized Textual Markers

The following markers do not decide active status:

- `[S]`
- Strategic
- City
- legacy labels
- old folder names
- old display names
- historical comments
- human-facing titles
- visual card labels

## Active Status Requires Evidence

A file, route, screen, card, section, or feature is active only when current evidence exists through one or more of:

- Section Code
- Route Registry
- Screen Registry
- Digital Twin
- Operations Registry
- Runtime import/reference
- Current router registration
- Current section ownership card

## Rule

No cleanup, protection, deletion, archive classification, or active-runtime decision may be based on text labels alone.
