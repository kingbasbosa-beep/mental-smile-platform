# Active Status Classification Standard V1

Date: 2026-07-02

## Classification Standard

| Status | Required Evidence |
|---|---|
| ACTIVE | Current router registration or current runtime import/reference plus current section ownership evidence. |
| PROTECTED | ACTIVE evidence plus protected route/role/ownership registry evidence. |
| PUBLIC | ACTIVE evidence plus public route/screen registry evidence. |
| PENDING | Registry/plan evidence exists, but current real runtime is missing or intentionally disabled. |
| LEGACY | Historical evidence exists and current active code/registry evidence is absent. |
| ORPHAN | File exists but no current import, route, registry, or ownership evidence is found. |
| DUPLICATE | Two or more active code paths provide the same current function without distinct ownership. |
| REMOVE_CANDIDATE | No real current function and no required current registry authority. |

## Evidence Priority

1. Current router registration
2. Current runtime import/reference
3. Current route registry
4. Current section/screen registry
5. Current digital twin
6. Current operations registry
7. Current ownership card
8. Textual label, folder name, or display name

Textual label evidence is last and cannot decide status alone.
