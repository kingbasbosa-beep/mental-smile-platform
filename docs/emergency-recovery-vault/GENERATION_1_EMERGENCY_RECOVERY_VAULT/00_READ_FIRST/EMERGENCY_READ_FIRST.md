## Purpose

The Emergency Recovery Vault (ERV) is the catastrophic reconstruction package for Mental Smile Generation 1.

It is used only if capsules, documentation, Git repository state, runtime structure, or project layout are damaged or lost.

## Difference Between Recovery Objects

| Object | Meaning |
|---|---|
| Capsule | Certified rebuild unit for a section, doctrine, federation layer, or generation map. |
| Snapshot | Textual fingerprint of a current state. |
| Archive | Governed memory and truth ownership layer. |
| Backup | Direct copy of files/data for restoration. |
| Emergency Recovery Vault | Minimal governed preservation package with enough certified maps, manifests, registries, and recovery order to reconstruct Generation 1 safely. |

## Use ERV When

- The capsule constellation is incomplete or damaged.
- The repository structure is lost.
- Critical registries or digital twins are missing.
- A future assistant needs a safe reconstruction order.

## Do Not Use ERV When

- A normal section capsule is enough.
- You want to add features.
- You want to bypass Code Gate, Active Documents, Archive ownership, or Owner decisions.
- You need runtime data or Firestore documents. The ERV intentionally does not store those.
