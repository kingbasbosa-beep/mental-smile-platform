# Entry/Auth Prompt Guide V1

Status: ACTIVE_SECTION_GUIDE

Section: Entry/Auth

Date: 2026-06-23

## Prompt Block Template

Each future Entry/Auth prompt must include:

- purpose
- visual rule
- psychological rule
- accessibility rule
- forbidden design choices
- expected output

## Splash Background Prompt

Purpose:
Create or revise the public entry background.

Visual Rule:
Calm, premium, readable, and not crowded behind buttons.

Psychological Rule:
No route should feel superior to client access.

Accessibility Rule:
Maintain contrast and visual clarity.

Forbidden Design Choices:
No confusing symbolic hierarchy between client and accessibility access.

Expected Output:
Background asset only.

## Login Background Prompt

Purpose:
Create or revise auth gateway background.

Visual Rule:
Identity/auth-focused without overpowering fields.

Psychological Rule:
Login should feel secure, not punitive.

Accessibility Rule:
High contrast behind form fields.

Forbidden Design Choices:
No hidden field areas or unreadable text zones.

Expected Output:
Login background asset only.

## Client Entry Button Prompt

Purpose:
Design Quick Access button.

Visual Rule:
Same family as Accessibility Client button.

Psychological Rule:
No hierarchy over Accessibility Client.

Accessibility Rule:
Icon, label, tooltip, speaker-ready metadata.

Forbidden Design Choices:
No medicalized or superior framing.

Expected Output:
Button asset or UI spec.

## Accessibility Client Entry Button Prompt

Purpose:
Design Accessibility Access button.

Visual Rule:
Same family and weight as Quick Access.

Psychological Rule:
Accessibility is a support path, not a separate human class.

Accessibility Rule:
Icon, label, tooltip, speaker-ready metadata.

Forbidden Design Choices:
No disability-marking visual treatment.

Expected Output:
Button asset or UI spec.

## Provider/Center Login Button Prompt

Purpose:
Design professional entry button.

Visual Rule:
Distinct from client buttons.

Psychological Rule:
Professional route should be separate, not dominant.

Accessibility Rule:
Clear auth expectation.

Forbidden Design Choices:
No client-room routing.

Expected Output:
Button asset or UI spec.

## Owner Login Button Prompt

Purpose:
Design owner entry if approved.

Visual Rule:
Protected authority route style.

Psychological Rule:
Owner route is protected coordination, not public user entry.

Accessibility Rule:
Clear login expectation.

Forbidden Design Choices:
No public owner shortcut without protection.

Expected Output:
Button asset or UI spec.

## External Web Button Prompt

Purpose:
Design Official Website button.

Visual Rule:
Clearly public web route.

Psychological Rule:
Informational path, not account path.

Accessibility Rule:
Label should clarify web destination.

Forbidden Design Choices:
No routing to protected dashboards.

Expected Output:
Button asset or UI spec.

## Language Button Prompt

Purpose:
Design Arabic/English toggle.

Visual Rule:
Readable in both locales.

Psychological Rule:
No language priority implied.

Accessibility Rule:
Tooltip and voice-ready label.

Forbidden Design Choices:
No hidden state or ambiguous flag-only control.

Expected Output:
Language button asset or UI spec.

## Speaker Assistance Icon Prompt

Purpose:
Create speaker assistance marker.

Visual Rule:
Small, clear, consistent.

Psychological Rule:
Means "can be explained by voice", not "disabled user".

Accessibility Rule:
Tap target large enough.

Forbidden Design Choices:
No stigmatizing marker.

Expected Output:
Icon asset or UI spec.

## Voice Label Prompt

Purpose:
Define concise voice labels for buttons.

Visual Rule:
Not applicable.

Psychological Rule:
Simple and respectful.

Accessibility Rule:
Short, language-safe, clear.

Forbidden Design Choices:
No clinical assumptions.

Expected Output:
Text label set.

## Exit/Back Button Prompt

Purpose:
Design cancel/back entry controls.

Visual Rule:
Visible but not dominant.

Psychological Rule:
Leaving should feel safe.

Accessibility Rule:
Clear label and tooltip.

Forbidden Design Choices:
No destructive wording.

Expected Output:
Button asset or UI spec.
