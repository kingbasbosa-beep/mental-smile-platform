Status: ACTIVE_GOVERNANCE_CARD

## Card

The Presentation Gallery is the governed poster presentation layer for Mental Smile. It displays platform explanation posters as images only and opens a dedicated fullscreen viewer.

## Boundaries

- Independent from Knowledge Cards.
- Independent from Markdown article content.
- No captions or generated text around posters.
- No booking, login, pricing, payment, appointments, or patient dashboard behavior.
