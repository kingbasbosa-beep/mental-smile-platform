## Content Review Matrix

| Content Category | Review Cycle | Owner | Review Focus | Archive Destination | Escalation |
|---|---|---|---|---|---|
| Notebook | Quarterly privacy review | Residential Tools Owner | Privacy, local-only wording, non-diagnostic framing. | Notebook Reflection Signals | Privacy / Owner if storage changes. |
| Image Anchor | Quarterly UI/privacy review | Residential UI Owner | Image purpose, removal clarity, no public profile implication. | Image Anchor Signals | Privacy if persistence changes. |
| Motivational Messages | Monthly content review | Residential Content Owner | Warmth, safety, no treatment promises. | Motivation Signals | Support/Safety if wording becomes sensitive. |
| Daily Reflections | Monthly support review | Accessibility Content Owner | Reflection safety, non-diagnostic language. | Motivation / Suggestion Signals | Safety if high-risk language appears. |
| Warnings | Monthly safety review | Safety Owner | Calm blocked-state wording and user-safe instructions. | Error State Signals | Governance / Technical if recurring. |
| Safety Messages | Monthly safety review | Support Owner | Boundaries, escalation clarity, no crisis replacement. | Support Signals | Owner if high risk. |
| Educational Messages | Quarterly content review | Content / Library Owner | Source suitability, no clinical replacement. | Link / External App Signals | Human-AI / Publication Governance. |
| Help Text | Quarterly UX review | Application UI Owner | Clarity, brevity, accessibility. | Tool / Link / Suggestion Signals | Accessibility Owner if unclear. |
| Placeholder Text | Quarterly localization review | Application UI Owner | No stale placeholder, accurate future readiness. | Audio / Error Signals | Product Owner if runtime status changes. |
| Titles / Descriptions | Quarterly localization review | Product UI Owner | Arabic-first style and English parity. | Screen / Card Signals | Localization Owner. |
| Dialogs / SnackBars | Monthly UX/safety review | Application UI Owner | Action clarity, transient-message safety. | Tool / Suggestion / Error Signals | Safety Owner for error/support copy. |
| Support Messages | Monthly support review | Support Owner | Safe support framing and response expectation. | Support Signals | Governance / Owner. |
| AI Prompt Entries | Owner approval before runtime | Human-AI Governance Owner | Scope boundary, no execution, no diagnosis. | Prompt Intent Signals | Owner required. |
