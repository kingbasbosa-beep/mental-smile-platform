## Strategic Summary Principle

Residential signals do not become strategy automatically.

They first require:

1. Runtime collection approval.
2. Aggregation.
3. Review.
4. Classification.
5. Strategic summary generation.
6. Owner delivery when appropriate.

## Publication Rules

1. Strategic summaries are not public by default.
2. Owner delivery requires reviewed aggregation output.
3. No raw private note content should be delivered.
4. Complaint and support summaries require high review before strategic circulation.
5. Every Strategic summary must remain traceable to signal families and magnet groups.
