# LIBRARY AGGREGATION POINT STRUCTURE V1

Operation ID: OP-LIBRARY-AGGREGATION-AND-OPERATIONAL-FOUNDATION-BLOCK-V1

Status: ACTIVE_DOCUMENTATION_STRUCTURE

Runtime connected: NO

## Purpose

The Library Aggregation Point is a section-owned summary collection structure.

It follows:

Collect.

Summarize.

Dispatch.

It does not analyze, decide, recommend, classify users, or profile users.

## Position

```text
Library Surface
↓
Library Signal Families
↓
Library Aggregation Point
↓
Dispatch Package
↓
Archive Receiver Copy
Strategic Planning Receiver Copy
```

## Allowed Responsibilities

- count content opens;
- count category opens;
- count tool opens;
- count external link opens;
- count search usage without search text;
- count suggestion starts/submissions by category only;
- count specialist-only content opens;
- count research reference opens;
- count VR specialist content opens;
- count official resource opens;
- count safety/diagnostic warning views.

## Forbidden Responsibilities

- analysis;
- recommendation;
- user classification;
- user profiling;
- identity storage;
- search text storage;
- suggestion body storage;
- diagnosis or medical data storage;
- content body storage;
- dashboard creation.
