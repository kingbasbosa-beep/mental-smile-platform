# LIBRARY AGGREGATION COLLECTION DOCTRINE V1

Operation ID: OP-LIBRARY-AGGREGATION-AND-OPERATIONAL-FOUNDATION-BLOCK-V1

Status: ACTIVE_COLLECTION_DOCTRINE

Runtime connected: NO

## Core Rule

Library Aggregation is not analytics.

Library Aggregation is not monitoring.

Library Aggregation is not recommendation.

Library Aggregation is not decision-making.

It is summary collection only.

## Allowed Summary Metrics

Library Aggregation may collect only:

- counts;
- category totals;
- content type totals;
- external link totals;
- tool totals;
- warning shown totals;
- specialist-only access totals;
- suggestion category totals;
- search used count only.

## Forbidden Data

Library Aggregation must not collect:

- search text;
- user identity;
- user profile;
- diagnosis;
- personal notes;
- suggestion body;
- private content;
- uploaded files;
- sensitive categories;
- medical history.

## Output

Output is summary reports only.

No raw events.

No personal records.

No user timelines.

No user profiles.
