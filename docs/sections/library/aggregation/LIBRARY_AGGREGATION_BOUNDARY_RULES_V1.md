# LIBRARY AGGREGATION BOUNDARY RULES V1

Operation ID: OP-LIBRARY-AGGREGATION-AND-OPERATIONAL-FOUNDATION-BLOCK-V1

Status: ACTIVE_BOUNDARY_RULES

Runtime connected: NO

## Library Aggregation Does

- collect counts;
- summarize counts;
- prepare dispatch packages.

## Library Aggregation Does Not

- analyze;
- decide;
- recommend;
- classify users;
- profile users;
- store content body;
- store client text;
- store search text;
- store diagnosis-related data;
- connect Monitoring;
- connect Administrative;
- create dashboards.

## Responsibility Split

Archive:

- preserves timeline summaries.

Strategic Planning:

- analyzes later.

Library Aggregation:

- collects, summarizes, dispatches.

## Final Rule

Collect.

Summarize.

Dispatch.

Never analyze.

Never decide.

Never classify.
