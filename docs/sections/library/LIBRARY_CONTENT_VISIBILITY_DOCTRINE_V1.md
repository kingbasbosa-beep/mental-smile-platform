# LIBRARY CONTENT VISIBILITY DOCTRINE V1

Operation ID: OP-LIBRARY-CONSTITUTION-AND-GOVERNANCE-BLOCK-V1

Status: ACTIVE_LIBRARY_DOCTRINE

Runtime effect: none

## Visibility Classes

Library content visibility classes:

- Public Client;
- Client Guidance;
- Specialist Only;
- Center Only;
- Provider Education;
- Internal Review Only;
- Archive Only.

## Special Restrictions

| Content Family | Visibility Rule |
| --- | --- |
| VR Exposure Content | Specialist Only |
| Clinical Training | Specialist Only |
| Research | Specialist / Professional / Research Context |
| Provider Education | Specialist / Center / Provider Education only |
| Client-facing mental-health content | Must include safety rule and avoid self-diagnosis encouragement |

## Client-Facing Boundary

No client-facing Library material should encourage:

- self-diagnosis;
- self-treatment;
- replacing professional assessment;
- urgent safety decisions without official help;
- medical conclusions based only on reading.

## Internal Review

Internal Review Only content is not public content.

It may be reviewed, edited, rejected, or archived.

## Archive Only

Archive Only content is historical or retained evidence.

It must not be presented as active public Library content.
