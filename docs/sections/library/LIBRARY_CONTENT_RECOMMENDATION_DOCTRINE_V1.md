# LIBRARY CONTENT RECOMMENDATION DOCTRINE V1

Operation ID: OP-LIBRARY-CONSTITUTION-AND-GOVERNANCE-BLOCK-V1

Status: ACTIVE_LIBRARY_DOCTRINE

Runtime effect: none

## Core Rule

Library recommendations are guidance and discovery only.

They are not treatment.

They are not diagnosis.

They are not clinical advice.

## Forbidden Recommendation Basis

Library recommendations must not be based on:

- diagnosis;
- disorder label;
- medical condition;
- sensitive identity;
- inferred mental state;
- crisis inference;
- private medical details.

## Allowed Recommendation Basis

Allowed recommendation basis:

- selected interests;
- selected content categories;
- previously opened general categories;
- manually selected learning goals;
- non-sensitive interaction summaries.

## Recommendation Metadata In Cards

Recommendation tags may appear only as metadata inside Library cards.

Allowed tags:

- interest;
- topic;
- learning goal;
- content type.

Forbidden tags:

- diagnosis;
- disorder;
- addiction status;
- trauma status;
- crisis status;
- sensitive identity.

No recommendation engine is created by card metadata.

## Recommendation Language Rule

Recommendations must avoid:

- "you have";
- "you need treatment";
- "this condition applies to you";
- "this is your diagnosis";
- ranked clinical priority;
- urgency unless the content is an official safety warning.

## Future Runtime Boundary

This block does not create a recommendation engine.

Any future Library recommendation runtime requires:

- Owner approval;
- operation record;
- safety review;
- localization review;
- aggregation boundary review.
