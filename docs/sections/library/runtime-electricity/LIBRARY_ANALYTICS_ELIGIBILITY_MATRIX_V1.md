# LIBRARY_ANALYTICS_ELIGIBILITY_MATRIX_V1

Status: ACTIVE

| Signal Family | Analytics Eligible | Reason |
|---|---|---|
| Screen Presence | YES | Counts public discovery surface demand |
| Category Selection | YES | Shows library content interest |
| Card Open | YES | Shows card-level demand |
| Profile Open | YES, future | Shows public profile discovery demand |
| Search / Filter / Sort | YES, future | Shows discovery friction and intent |
| External Resource | LIMITED | Must avoid personal destination tracking |
| Registration | LIMITED | Intent only, no personal data |
| Accessibility | YES | Accessibility readiness demand |
| Suggestion / Support | REVIEW_REQUIRED | Governance review may be needed |
| Navigation | YES | Helps identify friction |

Rule: Analytics may use counts and categories only. No identity, no free text, no personal content.
