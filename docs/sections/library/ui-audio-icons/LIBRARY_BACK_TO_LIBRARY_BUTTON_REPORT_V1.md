# Library Back To Library Button Report V1

## Purpose

Add visible Back-to-Library affordances to nested Library provider pages so the Owner and visitors can return to the main Library page without relying on hidden or ambiguous controls.

## Implementation

Visible Back-to-Library placement added to:

- Specialist branch detail pages
- Center branch detail pages
- Specialist category list page
- Center category list page

Existing provider back behavior was preserved and routed to the existing Library web route.

## Route

Back-to-Library route: `/web/library`

Route constant: `Routes.webLibrary`

## Validation

Back-to-Library buttons added count: 2 reusable placements

Nested provider pages covered: 22

Routes invented: NO

Login behavior changed: NO

Navigation behavior changed beyond requested Back-to-Library affordance: NO
