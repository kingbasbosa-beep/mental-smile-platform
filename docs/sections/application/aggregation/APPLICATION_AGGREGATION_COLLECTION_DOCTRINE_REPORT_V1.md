## Summary

The Application Aggregation Collection Doctrine was registered as an active doctrine for the Application Aggregation foundation.

The doctrine confirms:

- Application Aggregation is a summary collection system only.
- It is not analytics.
- It is not monitoring.
- It is not recommendation infrastructure.
- It is not a decision system.
- It produces summary reports only.
- It produces no raw events, personal records, user timelines, or user profiles.

## Doctrine Added

Allowed responsibilities:

- count signals;
- count route openings;
- count card interactions;
- count language changes;
- count website clicks;
- count exit page opens;
- count category usage;
- create hourly, daily, and weekly summaries;
- prepare archive copy;
- prepare planning copy.

Forbidden responsibilities:

- user analysis;
- user classification;
- user identification;
- user profiling;
- storing content or identity;
- recommendations;
- alerts;
- interventions.

## Dual Output Rule

Future generated summary reports must produce:

- Archive Receiver Copy
- Strategic Planning Receiver Copy

Both copies receive the same package.

Application Aggregation Point performs no transformation or analysis.
