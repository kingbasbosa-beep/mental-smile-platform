# BLOCK_3_CARD_DNA_GUIDE_V1

Status: ACTIVE_GUIDE

## Mandatory Card DNA

Each Card runtime object must expose:

- Card GUID
- Card Type
- Owner
- Section
- Status
- Version
- Lifecycle
- Created By
- Created Operation
- Last Review
- Guide
- Constitution
- Registry
- Dependencies
- Consumers
- Signals
- Collections
- Health
- Compliance

## DNA Lock

Cards with missing mandatory DNA are shown with warnings or compliance errors.

Runtime does not activate missing DNA silently.
