# MEDIA_LIBRARY_AND_CREATIVE_MUSEUM_V1

Status: CURRENT

Owning Layer: Release Ecosystem and Institutional Memory

Purpose: Define the official media library and creative museum for Mental Smile release assets.

## Media Library Scope

The Media Library stores current usable assets required for releases and public communication.

It includes:

- Screens
- Buttons
- Icons
- Illustrations
- Animations
- Videos
- Store Assets
- Website Assets
- Press Assets
- Presentation Assets
- Social Assets
- Creative Collections

## Creative Museum Scope

The Creative Museum preserves historical creative work.

It includes:

- Retired screens
- Retired buttons
- Retired icons
- Retired illustrations
- Earlier visual directions
- Rejected art directions
- Superseded presentation material
- Old campaign visuals
- Visual evolution references

## Separation Rule

Media Library is for active and approved release-ready assets.

Creative Museum is for historical, retired, rejected, superseded, or reference-only creative material.

## Asset Record Fields

Each asset should eventually record:

- Asset name
- Asset type
- Current status
- Owning section
- Source file
- Usage surface
- Approval state
- Release version
- Archive location
- Supersedes
- Superseded by

## Status Values

Allowed status values:

- ACTIVE
- RELEASE_READY
- DRAFT
- SUPERSEDED
- RETIRED
- REJECTED
- ARCHIVE_ONLY
