# COMMUNITY_CONFLICTS_PLAYBOOK_V1

Scope: Community disputes, misunderstanding, tension, and non-critical conflicts.

Principle: De-escalation and restoration first.

Steps:
1. Intake report.
2. Separate parties if needed.
3. Review evidence.
4. Offer education or mediation path when safe.
5. Apply temporary restriction only when needed.
6. Record outcome.
7. Archive.
