# GitHub Role Constitution V1

Operation: NEW_REPOSITORY_BIRTH_AND_ROLE_GOVERNANCE_V1

## GitHub Role

GitHub is the repository, governance, collaboration, and temporary public landing surface for the clean Mental Smile Platform repository.

## GitHub Is

- source repository host
- governance host
- operation log host
- temporary GitHub Pages landing source
- future technical presentation source

## GitHub Is Not

- official production replacement for Firebase
- legacy archive host
- uncontrolled history dump
- public-landing legacy host
- materialization executor by default

## GitHub Pages Rule

GitHub Pages may be used only for temporary landing preview unless a later owner-approved operation changes this role.

## Workflow Rule

No workflow is created by the repository birth operation.

Any workflow must be created by a separate deployment or publishing operation.

## Branch Rule

Branch strategy is not created by this operation.

Branch governance must be defined before production deployment.
