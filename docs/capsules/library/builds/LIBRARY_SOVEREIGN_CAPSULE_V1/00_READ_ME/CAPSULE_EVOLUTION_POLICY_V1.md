# CAPSULE_EVOLUTION_POLICY_V1

Status: ACTIVE

## Purpose

Define Library capsule evolution.

## V2 / V3 Creation

New versions are created only from the current Library Active Documents Registry. Certified previous capsule folders remain immutable.

## Supersession

When a later Library capsule becomes active, this capsule receives `superseded_by`, `retirement_date`, and loses `ACTIVE_CURRENT`.

## Historical Availability

Historical capsules remain available for audit only and must not be used as active truth unless re-certified.
