# Library Audio Icon User Behavior Card V1

## User-Facing Meaning

The small headphone/audio-support icon is a visual preview affordance. It signals that the card has a guided larger-image preview.

## Tap Behavior

When the icon is tapped:

1. The current card stays in place.
2. The normal card tap/open action is not triggered.
3. A larger visual preview opens.
4. The preview can be closed without changing the page destination.

## Non-Behavior

The icon does not:

- Play audio.
- Start TTS.
- Record anything.
- Write to Firebase.
- Write to Firestore.
- Write to Storage.
- Change the card route.
- Create a signal beyond existing local Library conventions.

## Applied Families

- Library cards
- Specialist cards
- Center cards
- Category cards
- Nested Library display surfaces
