## Review Matrix

| Resource Category | Review Cycle | Review Owner | Maintenance Owner | Review Focus | Escalation |
|---|---|---|---|---|---|
| Applications | Quarterly | Application UI Owner | Public Web / Channel Owner | Link validity, destination safety, official status. | Owner if official destination changes. |
| Tools | Quarterly | Residential Tools Owner | Residential / Accessibility Tools Owner | Tool relevance, labels, accessibility, user safety. | Technical + Accessibility review. |
| Links | Quarterly | Residential Resource Owner | Residential Resource Owner | Broken links, relevance, safe wording. | Archive/Strategic if resource category changes. |
| Groups | Monthly | Support / Community Owner | Support Owner | Group safety, moderation readiness, support boundaries. | Governance / Owner. |
| External Websites | Quarterly | Resource Owner | Resource Owner | Trust, safety, availability, replacement needs. | Governance if unsafe. |
| Government Resources | Quarterly | Accessibility Resource Owner | Accessibility Resource Owner | Current authority, country relevance, official status. | Legal/Governance if uncertain. |
| NGOs | Quarterly | Accessibility Resource Owner | Accessibility Resource Owner | Credibility, scope relevance, support value. | Governance if unverified. |
| Accessibility Resources | Monthly | Accessibility Owner | Accessibility Owner | Accessibility quality, semantics, icon readiness. | Accessibility Governance. |
| Support Resources | Monthly | Support Owner | Support Owner | Safety, responsiveness, escalation fit. | Governance / Owner. |
| Educational Resources | Quarterly | Content / Library Owner | Content / Library Owner | Domain relevance, public safety, non-clinical boundary. | Human-AI / Publication Governance. |
| AI Resources | Owner approval before activation | Human-AI Governance Owner | Human-AI Governance Owner | AI boundaries, safety, role scope, no execution before approval. | Owner. |
