## Purpose

Define the future Firebase governance boundary for Residential anonymous signal packages.

This card does not modify Firebase.

This card does not deploy rules.

This card does not create collections.

## Residential Signal Principle

Residential runtime signals are anonymous demand signals.

They represent usage, intent, accessibility demand, support intent, navigation patterns, and product feedback at a governed metadata level only.

## Approved Future Firebase Scope

Future Firebase use may support:

- anonymous event storage
- aggregate counters
- archive package inputs
- strategic summary inputs

Future Firebase use must not support:

- user identity tracking
- personal profile storage
- diagnosis storage
- notebook content storage
- uploaded image storage
- device fingerprinting

## Candidate Future Collections

- `residential_signal_events`
- `residential_signal_aggregates`
- `residential_signal_archive_packages`
- `residential_strategic_summary_inputs`
