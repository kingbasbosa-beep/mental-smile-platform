# Residential Prompt Guide V1

Status: ACTIVE_SECTION_GUIDE

Section: Residential

Date: 2026-06-23

## Purpose

This guide stores Residential prompt families only.

It does not import the ARCHIVE_ONLY global prompt model. Future prompts for Residential should be saved here or in a Residential-owned prompt archive.

## Prompt Families

### Room Design Prompts

Use for:

- Client Room background changes
- Accessibility Room background changes
- room responsive placement
- desk, TV, monitor, notebook, and wall-slot layout

Residential rule: room prompts must not introduce accounts, booking, diagnosis, payment, or provider assignment.

### Image Prompts

Use for:

- Residential backgrounds
- fixed card icons
- room button assets
- papyrus backgrounds
- visual accessibility icons

Residential rule: image prompts must identify the target surface and whether the asset is fixed, replaceable, or future-only.

### Button Prompts

Use for:

- exit cup placement
- YouTube gateway placement
- temporary photo placement
- notebook feather placement
- safe navigation behavior

Residential rule: button prompts must state whether behavior is local, external, or route navigation.

### Card Prompts

Use for:

- Accessibility Room wall cards
- card labels
- card icons
- page routes
- placeholder pages

Residential rule: cards must remain fixed until a future card expansion is approved.

### Text Message Prompts

Use for:

- notebook messages
- WhatsApp messages
- success messages
- accessibility simplified copy
- speaker placeholder copy

Residential rule: messages must not create diagnosis, clinical instruction, or persistent client memory.

### Future Update Prompts

Every future Residential update prompt should include:

- affected room or page
- route if any
- asset impact
- localization impact
- signal impact
- report impact
- explicit no-client-identity confirmation
