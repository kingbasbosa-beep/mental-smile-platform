# ARCHIVE_TRAFFIC_LANGUAGE_GUIDE_V1

Status: ACTIVE ARCHIVE LANGUAGE GUIDE

Archive Role: Language Engine of Mental Smile

## Purpose

Archive is no longer treated as storage only.

Archive is the readable language layer that explains every governed movement inside Mental Smile.

Every package, signal, summary, dispatch, magnet, vault, and destination must be readable as a governed traffic sentence.

## Archive Language Questions

Each traffic unit must answer:

- Who emitted it?
- From which section?
- From which outbox?
- Why was it emitted?
- Which signal generated it?
- Which package family carries it?
- Which magnet attracts it?
- Which archive destination receives it?
- Which vault stores it?
- Which summary is generated?
- Which dispatch may happen?
- Who consumes it?
- Who owns it?
- Which AI memory receives it?
- Which privacy class protects it?
- Which retention rule governs it?
