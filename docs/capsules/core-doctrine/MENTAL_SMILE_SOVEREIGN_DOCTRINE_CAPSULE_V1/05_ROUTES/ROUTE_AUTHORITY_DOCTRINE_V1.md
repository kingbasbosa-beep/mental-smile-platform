# ROUTE_AUTHORITY_DOCTRINE_V1

Status: ACTIVE

## Purpose

Explain why routes became authority objects.

Routes are not just navigation strings. They define which runtime surfaces are reachable.

## Rule

A route must survive only when it opens current active runtime with current purpose. Legacy routes, aliases to obsolete skeletons, and placeholder routes must not remain active.
