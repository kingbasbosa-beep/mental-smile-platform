# CAPSULE_EVOLUTION_POLICY_V1

Status: ACTIVE

## Purpose

Define how the Core Doctrine Capsule evolves.

## V2 Creation

V2 may be created only when Mental Smile enters a new certified constitutional generation or when Owner approves a fundamental doctrine change.

## V3 Creation

V3 follows V2 and must explicitly identify which Generation 1 doctrine remains active, which doctrine is superseded, and why.

## Immutability

Certified doctrine capsules are immutable. Corrections create a patch or a new version.

## Retirement

This capsule can be retired only by a later certified Core Doctrine Capsule and an updated Active Documents/Archive authority chain.

## Historical Availability

Retired doctrine capsules remain available for historical learning but cannot govern runtime or future capsules unless re-certified.
