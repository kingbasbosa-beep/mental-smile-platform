# PHILOSOPHY_TRANSITION_MAP_V1

Status: CERTIFIED

## Purpose

Explain the major philosophy transitions in Mental Smile Generation 1.

## Transition Map

| From | To | Reason |
|---|---|---|
| Feature-first building | Governance-first building | Feature speed created ambiguity; governance restored clarity. |
| Folder-name authority | Code authority | Folder names and labels became unreliable. |
| Historical documentation as truth | Active Documents as truth | Historical docs preserved past decisions but could mislead current work. |
| Direct section ownership of data | Archive-owned durable memory | Direct writes created boundary risks. |
| UI clicks as local-only events | Signals as governed events | Runtime needed observable electricity without identity leakage. |
| Signal names only | Signal + Magnet | Names alone did not prove destination semantics. |
| Passive Firestore collection | Archive Intake pipeline | Storage without intake is not governance. |
| Manual memory | Digital Twins | Future AI needed a stable navigation layer. |
| Cleanup as deletion only | Cleanup as authority correction | Removing files was not enough; authority had to be retired. |
| Capsule as backup | Capsule as sovereign rebuild unit | Backup preserves bytes; capsule preserves meaning. |

## Core Discovery

Mental Smile matured when it stopped asking "Does this file exist?" and started asking "Does this object have current authority?"
