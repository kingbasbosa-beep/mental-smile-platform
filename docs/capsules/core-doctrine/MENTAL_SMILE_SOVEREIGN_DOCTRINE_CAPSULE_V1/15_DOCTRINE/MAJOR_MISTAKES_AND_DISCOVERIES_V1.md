# MAJOR_MISTAKES_AND_DISCOVERIES_V1

Status: CERTIFIED

## Purpose

Record major mistakes and discoveries without shame and without letting them govern runtime.

## Major Mistakes

| Mistake | Discovery |
|---|---|
| Leaving legacy routes active | Active cleanup must verify reachability, not only intent. |
| Allowing placeholders to remain visible | Empty screens still shape user trust. |
| Letting old labels imply status | Textual markers have no authority. |
| Treating docs as equally current | Active Documents were necessary. |
| Assuming a Firestore write would work after local edits | Deployed rules and exact payload shape matter. |
| Treating signals as enough without destinations | Magnets and Archive destinations are required. |
| Copying philosophy forward too freely | Philosophical noise can contaminate future AI generation. |

## Major Discoveries

- A platform can be made portable through capsules.
- Archive can become a constitutional intake gate, not passive storage.
- Code can protect meaning when labels fail.
- Owner taste and Owner decisions are architectural inputs.
- Runtime electricity needs doctrine before scale.
- Future AI needs curated truth, not broad scanning.
