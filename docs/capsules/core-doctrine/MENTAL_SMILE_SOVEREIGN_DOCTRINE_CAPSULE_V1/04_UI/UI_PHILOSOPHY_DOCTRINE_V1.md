# UI_PHILOSOPHY_DOCTRINE_V1

Status: ACTIVE

## Purpose

Explain why UI became governed.

UI is not decoration in Mental Smile. It is an active trust surface. A visible card, shortcut, note, exit button, or placeholder shapes what the Owner and users believe is real.

## Rule

No active placeholder. No visible dead end. No obsolete card preserved for nostalgia. Every visible UI element must have current purpose, code, owner, route or behavior, and registry support.
