| Priority | Evidence | Required Result |
|---|---|---|
| 1 | Destination Code | Must exist and be active. |
| 2 | Signal Family | Must be accepted by destination. |
| 3 | Magnet | Must match destination purpose. |
| 4 | Package Family | Must be accepted by destination. |

| 6 | Retention Class | Must be present and allowed. |

## Priority Rule

Lower-priority evidence cannot override a failed higher-priority requirement.

Example: a valid magnet cannot rescue an unknown destination code.
