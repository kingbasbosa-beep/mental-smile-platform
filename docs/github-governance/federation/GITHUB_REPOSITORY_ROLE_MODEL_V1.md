# GitHub Repository Role Model V1

Status: ACTIVE_GOVERNANCE_FOUNDATION
Date: 2026-07-08
Scope: Intended GitHub federation repository roles

## Development Repository

Purpose:

- Active Flutter runtime.
- Current source code.
- Active feature work.
- Active governance docs.
- Current operations reports.

Allowed:

- `lib/`
- `assets/`
- `web/`
- `android/`
- Firebase config references.
- `docs/constitutional-baseline/`
- `docs/sections/`
- `docs/operations/`

Not allowed:

- Acting as the long-term historical dump.
- Acting as the public philosophical website.
- Acting as legacy landing storage.
- Mixing temporary deployment with official production identity.

Current repository status:

- The current repository is still hybrid, but `post-separation-pure-dna-v1` is the active development branch.

## History Repository

Purpose:

- Historical memory only.

Allowed:

- Old reports.
- Legacy docs.
- Frozen branch references.
- Old public landing packages.
- Retired systems.
- Decision history.
- Recovery material.

Not allowed:

- Active runtime.
- Active publishing.
- Current product identity.
- Current landing page.

Current status:

- A dedicated history repository is an intended model item, not yet separated in this operation.

## Documentation/Main Repository

Purpose:

- Stable final documentation.
- Stable governance truth.
- Public technical summaries.
- Release declarations.

Allowed:

- Final governance docs.
- Final public technical documentation.
- Stable release declarations.
- Platform state summaries.

Not allowed:

- Active experimental runtime work.
- Old history philosophy presented as current truth.
- Misleading outdated landing pages.
- Temporary deployment confusion.

Current status:

- `origin/main` exists and is older than the active development branch.
- Main is intended to become stable documentation/governance truth, not temporary publishing output.

## Deployment Surface

Purpose:

- Temporary public web publishing.

Allowed:

- Generated Flutter `build/web` output.
- `.nojekyll`.

Not allowed:

- Source code.
- Docs.
- Archive material.
- README philosophy.
- `public-landing` source.
- Old static website content.

Current status:

- `gh-pages` is the intended temporary publishing branch.

## Recovery Archive

Purpose:

- Frozen recovery packages.
- Rebuild material.
- Emergency restoration documentation.

Allowed:

- Recovery vaults.
- Capsules.
- Rebuild manifests.
- Historical source snapshots.

Not allowed:

- Active public runtime identity.
- Active deployment output.
- Unlabeled current product truth.

Current status:

- Recovery material currently lives inside the hybrid repository under archive, capsule, and recovery vault areas.
