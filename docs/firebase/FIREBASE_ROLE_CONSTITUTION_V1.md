## Firebase Role

Firebase is the future official production hosting and backend surface for Mental Smile Platform.

## Firebase May Govern

- official production Hosting
- Authentication
- Firestore
- Storage
- Functions
- production deployment records

## Firebase Is Not

- GitHub Pages replacement
- temporary landing preview source
- legacy static host
- uncontrolled deployment target
