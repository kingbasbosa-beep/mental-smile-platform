## Folder Roles

### app/

Current application/runtime materialization target.

This folder will later receive Flutter runtime from approved capsules only.

### presentation/

Technical and product presentations for GitHub, investors, partners, and publishing.

No app runtime belongs here.

### landing/

Temporary landing page source for GitHub Pages public preview.

GitHub Pages is temporary public landing only.

### website/

Future official website material.

This is not active production yet.

### docs/

Current governance and operating truth.

### docs/repository/

Repository identity, structure, scope, and responsibility records.

### docs/github/

GitHub role, branches, Pages, workflow, and publishing governance.

### docs/firebase/

Firebase role, Hosting/Auth/Firestore/Storage/Functions governance.

### docs/codex/

Codex operating rules and AI interpretation rules.

### docs/capsules/

Capsule registry and capsule import records only.

### docs/materialization/

Capsule materialization logs, maps, and import decisions.

### docs/deployment/

Deployment plans and publishing records.

### docs/operations/

Repository operation registry and index for this clean repository.

### .github/

GitHub configuration area.

### .github/workflows/

Workflow location. No workflow is created by this birth operation.
